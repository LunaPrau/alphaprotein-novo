# ALPHAPROTEIN NOVO GENERATOR MODEL PARAMETERS PROHIBITED USE POLICY

**Last Modified:** 2026-10-05

**AlphaProtein Novo** is a generative design pipeline for *de novo* protein and
enzyme design developed by [Google DeepMind](https://deepmind.google/). The
pipeline consists of the AP Novo Generator, followed by optional resequencing
with LigandMPNN, AlphaFold 3 structure prediction and filtering based on the
metrics from AlphaFold 3 (collectively the “**AP Novo Pipeline**”). LigandMPNN
and AlphaFold 3 are governed by their respective terms, conditions and licenses.

The AP Novo Generator generates 3D protein structures and amino acid sequences
conditioned on Input. We make the trained AP Novo Generator model parameters and
output generated using those model parameters available free of charge for
certain non-commercial uses in accordance with the
[AP Novo Generator Model Parameters Terms of Use](https://github.com/google-deepmind/alphaprotein-novo/blob/main/WEIGHTS_TERMS_OF_USE.md)
and the restrictions set out below. This policy uses the same defined terms as
the
[AP Novo Generator Model Parameters Terms of Use](https://github.com/google-deepmind/alphaprotein-novo/blob/main/WEIGHTS_TERMS_OF_USE.md).

        work.
